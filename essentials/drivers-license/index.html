미시건 운전면허 발급 — 한국 면허는 시험 없이 바꾼다

미시건은 한국과 운전면허 상호인정 협약이 있어 한국 면허가 있으면 필기·실기 없이 교체됩니다. 담당은 DMV 가 아니라 Secretary of State(SOS)입니다.

미시건은 DMV 가 아니라 SOS 입니다

다른 주에서 DMV 라고 부르는 곳을 미시건은 Secretary of State(SOS) 가 맡습니다. "SOS 사무소"가 곧 면허·차량 등록 창구입니다. 사무소 방문은 온라인으로 예약하고 가며, 예약하면서 신청서도 미리 씁니다(pre-apply).

한국 면허는 시험 없이 바꿉니다

이게 미시건에서 가장 값진 사실입니다. 미시건은 한국과 운전면허 상호인정 협약을 맺은 주라(캐나다·독일도 같음), 유효한 한국 면허를 가지고 가면 필기시험·실기시험 없이 미시건 면허로 교체됩니다. 시력 검사와 사진 촬영만 합니다. 텍사스 같은 다른 주에서 필기·실기를 다시 보는 것과 완전히 다릅니다.

SOS 핸드북("What Every Driver Must Know", 2025-10 판) 1장이 이렇게 씁니다 — 다른 미국 주, 캐나다, 독일, 대한민국 면허는 필기·TIP(임시허가)·실기 없이 전환할 수 있다. 근거 법은 MCL 257.302a 입니다. 단 한국 면허가 만료된 상태면 협약이 안 먹힙니다 — TIP 을 받고 실기를 봐야 합니다(같은 핸드북). 한국에서 갱신하고 오세요.

챙길 것 (SOS-428 인정 서류표 Rev. 6/26 기준) - 한국 운전면허증 원본 (유효기간 안). 외국 면허는 "운전 경력 증명"으로만 인정되고 신분·체류 증명으로는 안 쓰입니다. 교환해도 한국 면허증은 돌려받습니다(주시카고 총영사관 안내) - 합법 체류 증명 1종 — 유효한 여권 + 유효한 미국 비자 + I-94 (F 비자는 I-20, J 비자는 DS-2019 를 함께). B1/B2 비자와 무비자(WT/WB) 입국은 안 됩니다. 영주권자는 영주권 카드. 이민 서류는 연방 SAVE 시스템으로 확인하는데 하루 넘게 걸릴 수 있어 다시 오라고 할 수 있습니다 - SSN 증명 1종 — SSN 카드·W-2·급여명세서 등. SSN 을 못 받는 신분이면 SSA 의 불가 확인서(SSA-L676), 1년 이내 것만 - 신분 증명 1종 — 여권이면 됩니다 - 미시건 거주 증명 2종 — 최근 90일 안에 발행된 것, 전자 사본 가능, 가족 이름 서류도 관계를 증명하면 됩니다 → 거주증명 서류

외국 서류는 번역이 있거나 영문 병기여야 합니다(SOS-428). 한국 면허증은 영문 운전면허증으로 받아 오거나, 국제운전면허증 또는 영문 번역을 같이 가져가면 창구에서 막힘이 적습니다. 협약 적용 여부는 창구 직원에 따라 안내가 다를 수 있으니, 핸드북 1장 문구를 보여 줄 수 있게 준비하세요.

비용과 기간 (2026-09 기준)

  • Standard 면허 $25, State ID $10. 요즘은 기본으로 REAL ID 규격으로 나옵니다
  • Enhanced 면허 $45 — 아래 "미시건에만 있는 것"
  • 창구에서 종이 임시면허를 받고, 카드는 우편으로 약 2~3주 (SOS FAQ 는 2주, 핸드북은 3주)
  • 결제는 현금·수표·카드(Visa·MasterCard·Discover·AmEx) 모두 됩니다

언제까지

SOS FAQ 가 명시합니다 — "미시건 법에는 유예기간이 없다(no grace period)." 거주를 시작하면(established residency) 바로 신청하라고 씁니다. 텍사스처럼 "90일" 같은 숫자가 없으니 거주 시작 즉시로 보고 움직이세요. 거주 증명 2종이 아직 없으면 그때까지는 기존 면허로 운전하고, 갖춰지는 대로 갑니다.

단기 체류자(관광·방문)는 한국 면허(+영문 번역 또는 국제면허)로 운전할 수 있습니다 (SOS FAQ).

REAL ID

2025년 5월 7일부터 국내선 탑승에 REAL ID 가 필요합니다. 미시건은 첫 발급 때 별도로 요청하지 않아도 REAL ID 규격으로 나옵니다(opt-out 하지 않는 한). 나중에 일반 카드를 REAL ID 로 바꾸면 정정 수수료 $9 (2026-09 기준). 합법 체류 증명이 있어야 합니다.

비시민권자가 알아 둘 것

  • 갱신은 온라인이 안 됩니다 — 비시민권자는 갱신 때마다 사무소에서 체류 신분을 다시 확인합니다(SOS FAQ). 비자·I-94 가 바뀌면 그 서류를 들고 갑니다
  • 이민 서류 SAVE 확인이 당일에 안 끝나면 카드 발급이 미뤄집니다. 비자 만료가 가까우면 먼저 갱신하고 가세요

미시건에만 있는 것

  • Enhanced license($45) — 캐나다 육로 국경을 여권 없이 넘을 수 있는 면허. 디트로이트 에서 캐나다(윈저)가 다리 하나 건너라 실제로 씁니다. 시민권자만 가능
  • 면허를 받으면 자동으로 유권자 등록됩니다(시민권자). 비시민권자는 해당 없음
  • 실기시험은 SOS 가 아니라 SOS 가 승인한 민간 시험업체(driver testing business) 에서 봅니다. 요금은 업체가 정하고 SOS 가 규제하지 않습니다. 한국 면허 협약 대상이면 볼 일이 없고, 면허가 만료됐거나 처음 따는 가족(18세 이상)에게 해당 — 필기(온라인 가능) → TIP → 30일 연습 → 실기 순서

다음 단계

차를 가져왔다면 차량 등록이 이어집니다 — 미시건 무과실 보험이 먼저 있어야 등록이 됩니다.
